# Release 0.2.5

- Bumped the crate and audit-report versions from 0.2.4 to 0.2.5.
- Since 0.2.4:
  - `claims-mcp rebase` replays a branch's ledger records onto main's under new ids and prints
    the old-to-new id mapping, so two branches that both wrote `claims.json` can merge (PR #35,
    issue #32).
  - Every MCP tool takes an optional `catalog` argument, so one call can name its own ledger
    (PR #34, issue #31).
  - The claims-audit skill gained a pull-request mode and the `claims_call.py` helper (PR #33).
  - The documentation site's claims viewer keeps its filters in a panel (PR #30).
  - Dependencies: the lock file moves rmcp from 3.7.0 to 3.8.0 (PR #24). The manifest keeps
    `rmcp = "3.7.0"` as its lower bound: nothing in 0.2.5 needs a 3.8.0 feature.
- No catalog format change: `SCHEMA_VERSION` stays 2.
- The audit notes record that PRs #34 and #35 were audited as claims (CLM-0078 to CLM-0130) and
  that PRs #33 and #30 were not.
