# claims-mcp 0.1.0: repository ready for public access

## Repository settings (applied through the GitHub API, not in git)
- The `Protect main` ruleset applies to the default branch, with no bypass actors, not even
  admins:
  - Changes reach `main` only through pull requests. No approvals are required, so the sole
    maintainer can merge, but review threads must be resolved.
  - The `fmt, clippy, build, test`, `test (windows-latest)`, `test (macos-latest)`,
    `MSRV (rust-version in Cargo.toml)`, and `audit report` checks are required, and the
    branch must be up to date before merging.
  - Force pushes and deletion of `main` are blocked.
- The `Protect release tags` ruleset blocks updating and deleting `v*` tags.
- The "Update branch" button is always shown, head branches are deleted on merge, and
  auto-merge is enabled.
- Dependabot alerts and security updates, secret scanning, and push protection are on.
- The wiki and projects are off, since documentation lives in the repository.
- The repository has a description and topics.

## Added
- `.github/dependabot.yml`: weekly grouped updates for cargo and for GitHub Actions, including
  the SHA-pinned actions.
- `SECURITY.md`: report vulnerabilities through GitHub private vulnerability reporting.
- README: a Security section, and release steps that describe the protected `main` and tags.
