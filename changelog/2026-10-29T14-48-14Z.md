# Commit-pinned anchors, absence refutations, and recheck (issue #21)

A refuted claim can now be traced to exact, checkable places: the text that makes the claim, and
either the code that contradicts it or a search showing the feature does not exist.

- **Model** (`src/model.rs`): `Evidence.anchor: Option<Anchor>` and
  `Claim.source_anchor: Option<FileAnchor>`. `Anchor` is `file` (`path`, optional `lines`,
  `commit`, `dirty`) or `search` (`pattern`, `case_insensitive`, `scope`, `hits`, `commit`,
  `dirty`). Both fields are omitted when absent, so existing seals stay valid and the schema
  version stays 2.
- **Pinning** (`src/anchor.rs`): the server validates anchors (relative path, no `..`, lines
  inside the file), records `HEAD` and a per-path `dirty` flag, and runs `git grep -c -E` itself
  for searches. A caller's `hits` must match the server's count, and every scope path must
  exist at the commit, so a misspelled directory cannot pass for a proven absence. Git is reached through the
  `RepoProbe` trait (`GitCli` in production, `FakeRepo` in tests), and only when an anchor is
  given, so catalogs outside git still work.
- **Tools** (`src/server.rs`): `add_claim`, `add_claims`, and `update_claim` take
  `source_anchor`; `add_evidence` takes `anchor`; new read-only `recheck` tool.
- **Recheck** (`src/recheck.rs`, `claims-mcp recheck [--json]`): compares every anchor on
  active claims with `HEAD` and reports `moved` (with the new line numbers), `changed`,
  `overturned`, `missing`, `commit_missing`, or `unpinned`. Git answers shared by several
  anchors are cached. The CLI exits 1 when any anchor is not current.
- **Audit report** (`src/report.rs`): matrix rows gain `refuting_locators`; new gap
  `refuted_without_source_anchor`.
- **PDF template** (`report/claims-report.typ`, `justfile`): mirrors both report changes, shows
  the source anchor ("Claim made at") and each evidence anchor on findings, takes the new
  `recheck` input to flag stale anchors inline and in an "Anchor recheck" section, and adds
  glossary entries. `just report` runs `recheck --json`.
- **Skill** (`skills/claims-audit/SKILL.md`): an *Absence* procedure (zero-hit search anchor plus
  a file anchor on where the feature would plug in, plus a source anchor). The old rule
  "absence of evidence is `not_enough_info`" now separates not having looked
  (`not_enough_info`) from a demonstrated absence (`refuted`). Re-audits start with `recheck`.
- **Docs**: README "Anchors" section, CLI and tool tables, report inputs; design spec sections
  3.1, 4, and 4.1.
- **Tests**: unit tests for validation, pinning, hunk overlap and line shifts, every recheck
  status, and report fields; server tests against a real temporary git repository, covering the
  full absence flow through to `overturned`; and a Typst test checking that the template formats
  anchors exactly as `Display` does.
