# PR #7 review fixes: Dependabot scope, immutable-tag caveat, go-public steps

## Changed
- `.github/dependabot.yml`: the header comment now says Dependabot moves an action's SHA
  and its version comment together only for actions pinned to a release tag.
  `dtolnay/rust-toolchain` is pinned to a SHA on its `master` branch, so it is bumped by
  hand.
- README, Releasing: tags are immutable, so a tag that fails the `release.yml` version or
  `main` check still uses up its version number, even though nothing was published.
