# Release 0.2.4

- Bumped the crate and audit-report versions from 0.2.3 to 0.2.4.
- Since 0.2.3: generated the official claims.json JSON Schema from the Rust catalog model,

  (PR #28, issue #26).
- The audit notes record that the 0.2.4 schema additions were not separately audited as claims.
