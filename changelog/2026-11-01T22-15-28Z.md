# Ledger claims no longer state counts the project doesn't promise

- Five active claims in `claims.json` stated a count that their sources don't promise, so each
  would go stale (and still read as supported) the next time a tool, status or method is added:
  - CLM-0016 ("references every one of the server's 10 tools"; the server has 12);
  - CLM-0079 ("All 12 MCP tools accept an optional catalog argument");
  - CLM-0042 ("each of the six write tools"; its source, issue #9, says "every write tool");
  - CLM-0074 ("The six recheck statuses documented in concepts/anchors.md");
  - CLM-0077 ("The five verification methods documented in concepts/integrity-and-methods.md").
- Each is retired and replaced by a claim that states the property without the count ("every
  tool the server registers", "every write tool", "the statuses documented ... match the enum"),
  with fresh evidence. Test-run counts recorded against a specific commit, and the 1-4 range of
  integrity levels, are kept: they are what their sources state.
- No code or documentation changed.
