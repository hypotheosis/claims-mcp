# Per-project audit notes

- New `report/audit-notes.example.toml`: every key of the report's notes sidecar (artifact,
  version, repository, method, assessment, points) with placeholder values and guidance on what
  belongs in an assessment and in points for the evaluator. Other projects start from it.
- `report/audit-notes.toml` says it holds claims-mcp's own self-audit notes and points to the
  example; the README inputs table and `just report` line say the same.
- `claims-audit` skill, Report step: writing the audited project's notes file is now part of
  producing a PDF (from the example, never claims-mcp's own file), and the build command uses
  the project's ledger and notes with the claims-mcp template path, plus `detail=full`.
- New test `typst_template_accepts_example_notes` renders the example in both detail levels.
