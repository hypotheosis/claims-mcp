# Release 0.2.1

- `version` 0.2.1 in `Cargo.toml` (and `Cargo.lock`) and in `report/audit-notes.toml`.
- Since 0.2.0: the `next_steps` MCP tool and `claims-mcp tldr` subcommand (PR #15); the PDF

- Breaking for scripts that call `just report` positionally: `detail` is now its first
  parameter (`just report summary <catalog>`).
