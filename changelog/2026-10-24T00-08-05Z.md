# Release 0.2.2

- `version` 0.2.2 in `Cargo.toml` (and `Cargo.lock`) and in `report/audit-notes.toml`.
- Since 0.2.1: the PDF report template, its text helpers, and the notes example are compiled
  into the binary; `claims-mcp report init [DIR]` writes them into a project and seeds
  `audit-notes.toml` with every setting commented out; the MCP server serves them as read-only
  resources under `claims://report/`; the `claims-audit` skill and README no longer point at
  paths in this repository (PR #19, issue #18). The implementation plan is marked as a
  historical record, and CLM-0034 is retired and replaced by CLM-0066 (PR #14, issue #1).
- The audit notes' assessment says the 0.2.2 additions were not audited as claims.
