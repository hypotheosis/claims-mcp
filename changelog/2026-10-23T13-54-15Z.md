# claims-mcp 0.1.0: PR #5 review fixes for CI and release

## Changed
- `release.yml` publishes only when the tagged commit is on `main`. The version job checks out
  full history and runs `git merge-base --is-ancestor "$GITHUB_SHA" origin/main`, so a
  matching tag on an unmerged branch commit fails before any build is published.
- README release install steps create `~/.local/bin` before `install`, and add PowerShell
  steps for the Windows `.zip`: check the hash with `Get-FileHash`, then `Expand-Archive`.
- The `ci.yml` header says which platforms the tests cover. The aarch64 Linux and x86_64 macOS
  release builds are compiled but not tested.
- Fixed the clippy command in the issue #4 changelog entry (missing `--` before `-D warnings`).

## Not changed
- `ubuntu-24.04-arm` stays in the release matrix. The repository is private, but the runner
  ran and passed this PR's aarch64 build.
