# claims-mcp 0.1.0: PR #3 review fixes for the Typst report

## Changed
- `just report` stamps `git describe --always --dirty`. When the stamp ends in `-dirty`, the
  report's Reproduce section checks out the base commit and says the PDF came from
  uncommitted changes.
- `report/audit-notes.toml` is marked as a per-audit snapshot, and its assessment no longer
  restates counts or gap status that the report computes from the catalog.
- The template strips trailing slashes from `repository`, so issue links never contain `//`.
- The Typst parity tests fail instead of skipping when `REQUIRE_TYPST=1` is set and `typst`
  is missing. The README notes that a green `cargo test` does not prove the check ran.

## Catalog
- CLM-0020 (no command execution in `src/`) and CLM-0024 (only `store.rs` touches the
  filesystem) were refuted as written by the test-only `std::process::Command` and `std::fs`
  use in `src/report.rs` (EVD-0040, EVD-0041), then retired.
- They are replaced by CLM-0035 and CLM-0036, scoped to non-test code and supported by greps
  cut at each file's trailing `#[cfg(test)]` module (EVD-0042, EVD-0043). CLM-0019 is
  re-adjudicated with the new children (EVD-0044).
