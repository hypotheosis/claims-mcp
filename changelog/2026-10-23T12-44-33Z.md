# claims-mcp 0.1.0: final review polish

## Changed
- `.gitignore` now ignores `.env`.
- `audit_report` `include_matrix` is a plain `bool` defaulting to true; read-only tools
  (`get_claim`, `list_claims`, `trace`, `audit_report`) carry `read_only_hint` annotations;
  the `update_claim` description spells out null, list, source, and integrity rules.
- Report code avoids allocations: children are borrowed `&Claim`, the verdict map is gone,
  integrity-level totals use static string keys, and `trace` walks neighbours as iterators.
- New tests: `read_only_tools_are_annotated`, `report_serializes_to_json`.
- `claims-audit` skill: parent-claim adjudication guidance, an "Errors and constraints"
  section, a sharper goalpost anti-pattern, and a clearer `update_claim` row.
- README notes the first-start compile time of `cargo run --release`.
- Design spec aligned with the implemented `list_claims`, `trace`, `@N`, and `derived_from`
  behavior.
