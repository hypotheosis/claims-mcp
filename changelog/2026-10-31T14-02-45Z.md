# Documentation site

- New mdBook site in `docs/site/` (mdBook 0.5.4), written for evaluators first: an introduction
  with a worked example; "Why claims-mcp" (the problem, how it works alongside formal
  verification such as Aeneas and Lean, and where it doesn't fit); concept pages; guides
  (install, first audit, CI, PDF reports, migrating); reference (MCP tools, command line,
  catalog format, security); and development. `just docs` builds it and `just docs-serve`
  serves it. The build output `docs/site/book/` is git-ignored.
- `.github/workflows/docs.yml` builds the site and checks its internal links with lychee
  (offline, with fragments) on pull requests that touch `docs/site/`. On `main`, it deploys to
  GitHub Pages. mdBook is pinned by version and SHA-256, and actions by commit.
- The README is slimmed to a front door: the pitch, when to use it, a quickstart and links. The
  site is canonical for detail. Sections moved: Install to `guides/install.md`; Run to
  `reference/cli.md`; Integrity seals to `concepts/seals.md`; Checking in CI to `guides/ci.md`;
  Migrating to `guides/migrating.md`; Tools to `reference/tools.md`; Anchors to
  `concepts/anchors.md`; TL;DR of next steps to `guides/first-audit.md`; Generate a PDF report
  to `guides/reports.md`; Catalog format to `reference/catalog-format.md`; Development, CI and
  Releasing to `development.md`.
- `claims.json`: CLM-0032, -0053, -0059 and -0065 (README documentation) are retired and
  replaced by CLM-0067 to -0070 about the site. CLM-0071 and its six children check the site's
  tool list, CLI subcommands and exit codes, recheck statuses, seal behaviour and verification
  methods against `src/`, with commit-pinned anchors. All supported.
- `report/audit-notes.toml` no longer says the catalog has no anchored evidence.
- Owner action needed before the first deploy: set the repository's Pages source to "GitHub
  Actions", and set the homepage to `https://hypotheosis.github.io/claims-mcp/`.
- Design and plan: `docs/superpowers/specs/2026-10-31-docs-site-design.md`,
  `docs/superpowers/plans/2026-10-31-docs-site.md`.
